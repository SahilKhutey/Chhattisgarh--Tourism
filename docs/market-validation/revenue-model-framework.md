# Revenue Model Framework — CG Tourism OS

## 1. Multi-Tiered Revenue Architecture
CG Tourism OS establishes a multi-sided revenue model prioritizing provider operating surplus:

```
┌────────────────────────────────────────────────────────┐
│               CG TOURISM OS REVENUE ENGINE             │
├──────────────────────────┬─────────────────────────────┤
│      SUPPLY SIDE         │        DEMAND SIDE          │
│   (Primary Monetization) │   (Auxiliary Monetization)  │
├──────────────────────────┼─────────────────────────────┤
│ 1. Qualified Lead Fees   │ 1. Cultural Trail Passes    │
│    (₹25 / inquiry)       │    (₹149 / digital pass)    │
│ 2. Booking Commissions   │ 2. Custom Itinerary Unlocks │
│    (5% Homestay, 8% Tour)│    (₹99 / offline route)    │
│ 3. Operator SaaS Tiers   │                             │
│    (₹199 - ₹499 / month) │                             │
└──────────────────────────┴─────────────────────────────┘
```

## 2. Revenue Stream Characteristics
1. **Qualified Lead Fees (`QUALIFIED_LEAD_FEE`)**:
   - *Payment Trigger*: Traveler phone number & dates verified, lead dispatched to host WhatsApp.
   - *Unit*: ₹25 / lead.
   - *Take Rate / Margin*: 80% contribution margin.
2. **Booking Commission (`BOOKING_COMMISSION`)**:
   - *Payment Trigger*: Experience completed without guest dispute.
   - *Unit*: 5–8% of gross booking value.
   - *Average Booking Value*: ₹4,267. Net revenue: ~₹256 / booking.
3. **Provider Pro Subscriptions (`PRO_PROVIDER_SUBSCRIPTION`)**:
   - *Payment Trigger*: Monthly automated recurring billing.
   - *Unit*: ₹499 / month flat.
   - *Margin*: 90% margin.
4. **Artisan & Cultural Trail Digital Passes (`ARTISAN_CULTURAL_TRAIL_PASS`)**:
   - *Payment Trigger*: Consumer checkout for offline multimedia guide.
   - *Unit*: ₹149 / pass (70% revenue share distributed to local tribal artisan cooperatives).
