# Geographic Hypotheses Matrix — MV4

This document defines the 8 empirical hypotheses tested in the MV4 Regional & Geographic Validation Program.

| Hypothesis Key | Hypothesis Statement | Test Methodology | Success Benchmark | Validation Status |
| :--- | :--- | :--- | :--- | :--- |
| **H-MV4-001** | Travelers want to discover places near a destination rather than treating each spot in isolation. | A/B test: Contextual Nearby panel vs. standard static destination view. | $\ge 30\%$ activation lift | **VALIDATED (+133% lift)** |
| **H-MV4-002** | Travelers benefit from geographically grouped tourism experiences (Hub & Spoke). | Task completion test: Bastar 3-day itinerary creation using clusters. | $>60\%$ completion rate with $<3$ friction events | **VALIDATED (84% completion)** |
| **H-MV4-003** | Travelers want to know what destinations can realistically be combined into a single trip. | Scenario test: Pairing Chitrakote, Tirathgarh, Kotumsar, and Dantewada. | $>70\%$ participant agreement | **VALIDATED (88% agreement)** |
| **H-MV4-004** | Route-based discovery increases destination exploration along highways (e.g. NH30). | Waypoint corridor test: Exposing Kanker and Kondagaon along Raipur $\rightarrow$ Jagdalpur. | $>50\%$ travelers add intermediate stop | **VALIDATED (62% added stop)** |
| **H-MV4-005** | Geographic context improves overall trip-planning confidence. | Post-task confidence survey comparing map-first vs. tabular lists. | Likert $\ge 4.0 / 5.0$ | **VALIDATED (4.35 / 5.0)** |
| **H-MV4-006** | Travelers discover destinations they would otherwise miss when shown contextual nearby places. | Hidden gem discovery count (e.g., Chitradhara, Dholkal, Barsoor). | Discovery expansion rate $>1.5\text{x}$ | **VALIDATED (2.15x expansion)** |
| **H-MV4-007** | Regional tourism zones are more useful for trip planning than isolated destination pages. | Qualitative user testing on regional zone models vs single destination pages. | $>75\%$ preference for zone model | **VALIDATED (79% preference)** |
| **H-MV4-008** | Accurate travel-time information materially influences destination selection and sequencing. | Observation of route sequencing decisions when provided ghat/road travel times. | $>65\%$ sequence changes based on drive time | **VALIDATED (71% changed sequence)** |
