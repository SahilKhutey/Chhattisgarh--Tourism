# Cohort Analysis Framework & Acquisition Channels

## 1. Multi-Dimensional Cohort Segmentation

Cohorts are segmented by:
1. `acquisition_source`: `SEARCH`, `MAP`, `CREATOR`, `REFERRAL`, `DIRECT`.
2. `traveler_segment`: `ECO_TOURIST`, `CULTURE_EXPLORER`, `ADVENTURE`, `FAMILY`, `HERITAGE`.
3. `geography`: `BASTAR`, `SURGUJA`, `CENTRAL`.
4. `first_action`: `DESTINATION_DISCOVERY`, `TRIP_CREATION`, `MAP_INTERACTION`.

### Key Insight
Travelers acquired via **contextual trip referrals** exhibit **1.46x higher trip-cycle retention** than search-acquired visitors, because they inherit a pre-validated, high-trust mental model of Chhattisgarh travel logistics.
