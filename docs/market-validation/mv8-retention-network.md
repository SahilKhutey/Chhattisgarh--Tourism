# MV8: Retention, Repeat Usage & Network Effects Foundation

## 1. Executive Summary

MV8 transitions the **CG Tourism OS** validation program beyond singular transaction creation (MV7) into **ecosystem durability and network expansion**:

```
MV1 Market Intelligence
        ↓
MV2 Consumer Problems
        ↓
MV3 Supply Validation
        ↓
MV4 Geographic Validation
        ↓
MV5 Content & Discovery
        ↓
MV6 Consumer MVP
        ↓
MV7 Transaction / Conversion
        ↓
MV8 Retention + Network Effects
```

### The Strategic Paradigm
> **Tourism is naturally episodic.** Do not blindly apply SaaS retention frameworks (such as DAU/MAU or pure weekly D7/D30 curves) as the core definition of product-market fit.

A traveler does not visit a remote Chhattisgarh waterfall every weekend, but will return when planning their next holiday, share an itinerary with companions, review their homestay, recommend the platform to peers, or explore an entirely new regional district.

MV8 measures:
1. **Trip-Cycle Retention**: Meaningful task return across real travel intervals.
2. **Relationship Retention**: Ongoing provider and creator participation.
3. **Network Effects**: Whether each interaction increases platform discovery utility for subsequent travelers.

---

## 2. The Four Pillars of MV8

1. **Retention**: Repeat meaningful tourism behavior (creating a second trip, booking in another district).
2. **Engagement**: Ongoing product use during active travel cycles (saving itineraries, sharing routes).
3. **Referral**: Viral organic traveler acquisition via structured itinerary sharing.
4. **Network Effects**: Cross-side density where more verified providers and authentic creator stories generate higher consumer discovery utility.

---

## 3. The 9-Stage Retention Lifecycle

Consumers advance across explicit lifecycle states:
```
DISCOVERED → ENGAGED → PLANNING → BOOKED → TRAVELING → COMPLETED → POST_TRIP → RETURNED → REFERRED
```

Meaningful activity is strictly defined:
- Valid: Destination discovery, saving places, trip creation, provider inquiries, bookings, reviews, itinerary sharing.
- Invalid: Page refreshes, passive homepage impressions, accidental clicks.
