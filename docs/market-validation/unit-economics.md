# Unit Economics & LTV/CAC Validation

## 1. Unit Economics Overview
Unit economics evaluate whether acquiring and servicing users generates sustainable contribution profit before scale.

### Core Equations
$$\text{CAC} = \frac{\text{Direct Acquisition Spend}}{\text{Acquired Users}}$$
$$\text{Activated CAC} = \frac{\text{Direct Acquisition Spend}}{\text{Activated Users}}$$
$$\text{Paying CAC} = \frac{\text{Direct Acquisition Spend}}{\text{Paying Users}}$$
$$\text{Contribution Margin} = \text{Revenue} - \text{Variable Cost}$$
$$\text{Unit LTV} = \left(\frac{\text{Contribution Margin}}{\text{Paying Users}}\right) \times \text{Expected Lifespan Cycles}$$
$$\text{Payback Period (Months)} = \frac{\text{Paying CAC}}{\text{Monthly Contribution per User}}$$
