# Jobs-To-Be-Done (JTBD) Validation Register

## The 6 Core Tourism Jobs

| Job Key | JTBD Title | Job Statement |
| :--- | :--- | :--- |
| `JTBD-1` | **Discover** | *"I want to discover interesting places in Chhattisgarh that match my specific passions and travel style."* |
| `JTBD-2` | **Decide** | *"I want enough trustworthy, verified practical information to decide whether a place is genuinely worth visiting."* |
| `JTBD-3` | **Plan** | *"I want to turn multiple disconnected places into a realistic, feasible daily trip without backtracking."* |
| `JTBD-4` | **Navigate & Spatial Sense** | *"I want to understand how to get there safely and know what is nearby along my corridor."* |
| `JTBD-5` | **In-Destination Utility** | *"I want reliable, accessible information while I am traveling, especially when connectivity drops."* |
| `JTBD-6` | **Local Economic Participation** | *"I want to find authentic local experiences, verified guides, homestays, and tribal craft producers."* |

## Validation Lifecycle Statuses
1. `UNTESTED` — Initial hypothesis without empirical interview backing.
2. `EMERGING` — Mentioned across 1–3 interviews, preliminary pattern.
3. `SUPPORTED` — Backed by repeated user statements and observed workarounds across multiple cohorts.
4. `STRONGLY_SUPPORTED` — Backed by direct observed behavioral failure in standard tools and high pain scores.
5. `INCONCLUSIVE` — Conflicting evidence or high variance by segment.
6. `INVALIDATED` — Travelers demonstrate existing tools solve the job effortlessly.

## JTBD Confidence Metric
$$\text{JTBD Confidence} = \frac{\text{Supporting Interviews}}{\text{Total Evaluated Interviews}} \times \left(1 + \frac{\text{Direct Behavioral Observations}}{\text{Total Observations}}\right)$$
