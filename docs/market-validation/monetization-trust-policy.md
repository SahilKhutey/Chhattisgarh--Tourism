# Monetization Trust Policy & Anti-Bias Governance

## 1. Trust Principles
Monetization must never compromise information integrity, regional safety, or traveler trust.

```
          ┌───────────────────────────────────┐
          │     UNBREAKABLE TRUST RULES       │
          ├───────────────────────────────────┤
          │ 1. Zero Pay-to-Rank Discovery     │
          │ 2. Independent Review Integrity   │
          │ 3. Free Public Safety Access      │
          │ 4. Explicit Promoted Disclosures  │
          │ 5. Provider Surplus Protection    │
          └───────────────────────────────────┘
```

## 2. Policy Matrix
| Policy Rule | Enforcement Mechanism | Failure Consequence |
| :--- | :--- | :--- |
| **No Ranking Alteration** | Organic destination ranking algorithms have no commercial bidding inputs. | Algorithmic isolation audited per deploy. |
| **Promoted Transparency** | Any featured carousel card must display a high-contrast `SPONSORED` badge. | Immediate takedown if badge is suppressed. |
| **Review Non-Interference** | Paying operators cannot remove, hide, or dispute negative traveler reviews without independent audit. | Automated compliance logging. |
| **Free Geographic Data** | All road access, waterfall seasonal timings, and emergency contacts are public domain. | Permanent architectural isolation. |
| **Fee Cap Protection** | Commission take-rate is hard-capped at 10% (5% for homestays) to prevent OTA monopolistic pricing. | Enforced in order schema. |
