# Canonical UI Primitives (`@/ui`)

This directory houses the single source of truth for canonical UI primitives in CG Tourism OS.

## Directory Layout
- `Button/`
- `Card/`
- `Badge/`
- `Input/`
- `Select/`
- `Dialog/`
- `Drawer/`
- `Tabs/`
- `Accordion/`
- `Skeleton/`
- `EmptyState/`
- `ErrorState/`
- `layout/` (`Container`, `Stack`, `Grid`, `Section`, `Page`)

## Cardinal Rule
One canonical primitive -> reused everywhere. No duplicate Card, Modal, Button implementations.
